Standard Endpoint Shapes

Method Path Description
POST/api/{table}Create new {table} record
GET/api/{table}List with pagination/filter/sort
GET/api/{table}/{id}Read by ID
PUT/api/{table}/{id}Full update by ID
PATCH/api/{table}/{id}Partial update by ID
DELETE/api/{table}/{id}Soft/hard delete as applicable

Auth header where required: Authorization: Bearer <token>. Requests/responses refer to real columns; import the sheet to avoid guessing.
